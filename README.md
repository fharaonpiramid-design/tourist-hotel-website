# tourist-hotel-website
3-star hotel website for Hotel "Turist" in Kyiv's Dniprovskyi district

## Запуск

Просто відкрийте файл `README.md` у браузері або скопіюйте HTML код в текстовий редактор та збережіть як `index.html`.

### Python
```bash
python -m http.server 8000
```
Потім перейдіть на `http://localhost:8000`

### Node.js
```bash
npx http-server
```
